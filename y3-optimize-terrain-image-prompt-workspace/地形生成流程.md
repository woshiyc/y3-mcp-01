完整使用流程
第一阶段：生成地形图提示词
使用 y3-optimize-terrain-image-prompt

告诉 Skill 你的地图设计意图（地形、水域、高度、风格）
Skill 输出：
正向提示词（用于文生图）
负向提示词（用于文生图）
后处理参数（记下 --capital 和 --node-counts，后面用）
第二阶段：生成图片
用正向/负向提示词在文生图工具（Midjourney/SD 等）生成地形图
把地形图送入 DA3MONO-LARGE 生成对应的高度图（灰度深度图）
验收地形图：无树木/建筑图标、水域颜色稳定、填满画布
第三阶段：地形生成（y3-gen-terrain-from-image）
Stage 0：前置准备
步骤	做什么	命令/操作
0.1	MCP 连接 + 获取地图尺寸	调用 get_map_info
0.2	CV 依赖检测	python scripts/check_cv_deps.py
0.3	提供两张图 + 后处理参数	告知地形图路径、高度图路径、--capital、--node-counts
0.4	创建输出目录	output/ 目录
0.5	高度图→高度网格	cv_height_reader.py → height_grid.npy
0.6	去光影→干净纹理图	cv_delighting.py → albedo.png
Round 1：地形识别（水域 + 纹理 + 高度 + 斜坡）
步骤	做什么	谁来做
1.1	色相聚类（输入 albedo.png）	cv_cluster.py 自动
1.1b	增强聚类分析	cv_cluster_analysis.py 自动
1.2	识别水域簇 + 区分深水/浅水/平面水	AI（输出 water_type_clusters.json）
1.3	大陆连通分割	cv_continent_split.py 自动
1.3b	水体类型细化	cv_water_classify.py 自动
1.4a	大陆纹理分组	gen_round1_csv.py --group-only 自动
1.4b	AI 分配纹理（无需分配高度）	AI（仅纹理 ID）
1.4c	纹理面板同步	ensure_terrain_textures MCP 自动
1.5	孤立水域修复	water_postprocess.py 自动
1.5b	高度边界分析	cv_height_boundary.py --height-grid 自动
1.5c	斜坡规划（标自然屏障）	AI 决策 → 用户确认
1.6	生成 CSV（含水类型/高度/斜坡）	gen_round1_csv.py --water-type-grid 自动
Stage 5：MCP 写入地形
Pass	写什么
Pass 1	裂缝（通常跳过）
Pass 2	地形高度（h=2/4/6 区域）
Pass 3	水体（深水/浅水/平面水）
Pass 4	斜坡
Pass 5	地面纹理

Round 2：后处理（装饰物 + 植被）
步骤	做什么	谁来做
2.0	从地形图识别桥梁	AI（对照 water_map.txt 验证坐标）
2.1	后处理规划（距离场/节点/道路/树木）	cv_postprocess_plan.py --capital ... --node-counts ... 自动
2.2	查看预览图，确认规划	用户确认，可调整后重跑
2.3	MCP 写入（桥梁+游戏节点+树木+道路）	mcp_entity_writer.py
2.4	植被填充	cv_vegetation_fill.py 自动
