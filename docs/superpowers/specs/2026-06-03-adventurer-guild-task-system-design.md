# 冒险者公会任务系统 设计文档

**日期**：2026-06-03
**项目**：类Majesty俯视角领地管理游戏（Y3引擎）
**状态**：待实现

---

## 1. 设计背景与目标

### 1.1 背景

本系统参考日式冒险动漫中的冒险者公会设计（如《哥布林杀手》《钢铁城的骑士》），取代Majesty原版的"旗帜指令"系统，提供更通用、更有深度的间接控制机制。

### 1.2 玩家角色

玩家同时担任**领主**与**冒险者公会会长**双重身份：
- 作为领主：管理领地建筑、资源、应对领地事件
- 作为公会会长：维护冒险者名册、发布任务、分配装备

### 1.3 核心设计目标

- 比Majesty旗帜系统更通用，可承载多种任务类型
- 玩家可操作内容更丰富（赏金设定、人员选择、装备配置）
- 经济决策有张力（高赏金 vs 节省资金、高风险 vs 低风险）
- 冒险者有生命感（成长、忠诚、离队、死亡）

## 2. 系统总览

### 2.1 任务生命周期

```
领地事件自动触发
玩家主动创建         →  [挂牌] → [报名] → [派遣] → [执行] → [结算]
```

| 阶段 | 操作方 | 内容 |
|------|--------|------|
| 生成 | 系统/玩家 | 领地事件触发或玩家手动创建任务 |
| 挂牌 | 玩家 | 设定赏金倍率、是否提供装备、报名截止时间 |
| 报名 | 冒险者AI | 符合条件的冒险者自主决定是否报名 |
| 派遣 | 玩家 | 从报名池中选人，补充装备 |
| 执行 | 系统 | 实时观战（主）+ 事件选择卡（偶发） |
| 结算 | 系统 | 发放奖励/惩罚，更新冒险者状态 |

### 2.2 核心数据关系

```
任务等级 ──────── 决定 ──→ 可报名冒险者等级下限
赏金倍率 ──────── 决定 ──→ 报名池规模 + 结算忠诚度变化
冒险者等级+技能 ── 决定 ──→ 基础战斗能力
装备 ──────────── 决定 ──→ 战斗表现加成
忠诚度 ─────────── 决定 ──→ 离队风险
```

## 3. 冒险者系统

### 3.1 等级体系

等级用整数值表示，用于跨系统计算（平均等级、等级差）：

| 等级 | 整数值 | 称号 | 可接任务范围 | 升级方式 |
|------|--------|------|------------|---------|
| F | 1 | 新手 | F级任务 | 初始 |
| E | 2 | 见习 | E级及以下 | 任务经验积累 |
| D | 3 | 铜牌 | D级及以下 | 任务经验积累 |
| C | 4 | 银牌 | C级及以下 | 任务经验积累 |
| B | 5 | 金牌 | B级及以下 | 任务经验积累 |
| A | 6 | 秘银 | A级及以下 | 任务经验积累 |
| S | 7 | 传奇 | S级及以下 | 仅随机成长事件触发，不可通过经验达到 |

> **任务范围说明**：冒险者可接"任务等级整数值 ≤ 自身等级整数值"的任何任务。高等级冒险者可以接低等级任务（不会因为太简单而拒绝，但经验收益衰减，见9.3）。

> **S级稀缺性**：S级冒险者只能通过任务中触发的"奇遇事件"或特殊随机成长解锁，保证稀缺性和惊喜感。

### 3.2 忠诚度系统

- **范围**：0 ~ 100
- **动摇阈值**：忠诚度 ≤ 20 时进入动摇状态
- **离队触发**：动摇状态下，任务失败或再次接到低赏金任务后，有概率永久离队
- **强制离队**：忠诚度降至 0 时必然离队

忠诚度变化规则：

| 事件 | 变化量 |
|------|--------|
| 任务成功 + 赏金1.5x | +15 |
| 任务成功 + 赏金1.25x | +10 |
| 任务成功 + 赏金1.0x | +5 |
| 任务成功 + 赏金0.75x | +2 |
| 任务成功 + 赏金0.5x | +0（不涨不跌，但动摇状态下仍有离队风险） |
| 任务失败（轻度） | -10 |
| 任务失败（重度/伤亡） | -20 |
| 专属奖励被触发 | +5（额外叠加） |
| 闲置（无任务）每游戏日 | -3 |

> **游戏日定义**：1游戏日 = 现实时间10分钟（具体数值待时间系统设计确认后调整）。闲置判定：冒险者不在任务中、不在休整状态，且玩家连续未派遣该冒险者满1整游戏日。扣减时机：每满1游戏日的闲置期结束时扣减一次（即闲置第1天结束时 −3，第2天结束时再 −3，以此类推；刚开始闲置的第1天内不扣减）。

### 3.3 技能成长

- **主要途径**：每次升级时，从该职业技能池中**随机解锁1个技能**（玩家无法干预）
- **偶发途径**：任务中触发"奇遇事件"，可额外学习特殊技能（包括跨职业稀有技能）
- 技能直接影响战斗表现，不同技能组合形成冒险者个体差异

### 3.4 冒险者招募

- 玩家通过建设公会设施、提升公会声望来吸引冒险者主动上门
- 公会声望受历史任务成功率、对冒险者待遇（赏金慷慨度）影响
- 高声望公会可吸引更高等级冒险者加入

## 4. 任务系统

### 4.1 任务等级

与冒险者等级对应，共7级：F / E / D / C / B / A / S

任务等级决定：
- 派遣人数上限（高等级任务允许组建更大队伍）
- 基础赏金额
- 失败后的后果严重程度
- 可报名的冒险者最低等级要求

### 4.2 任务来源

**自动触发任务（领地事件）**：

| 领地事件 | 任务类型 | 时效性 | 不处理后果 |
|---------|---------|--------|-----------|
| 怪物巢穴出现 | 讨伐 | 有期限 | 期限到后怪物袭击领地建筑 |
| 遗迹被发现 | 探索 | 有期限 | 其他势力抢先占领 |
| 商队被劫 | 护送/追剿 | 有期限 | 损失贸易收入 |
| 疾病爆发 | 调查 | 有期限 | 蔓延影响更多建筑 |

**玩家主动发布任务（战略任务）**：
- 扩张探索：开发新区域
- 外交任务：与其他势力建立联系
- 侦察任务：获取情报
- **S级战略任务**：征讨领主级威胁（远古龙、魔王军、大型怪物群），仅玩家主动发布，需要达到特定领地声望或故事条件解锁
- 以上无时效惩罚（不会因为玩家迟发布而产生负面后果），但部分战略目标会因地图上其他势力的行动而先行消失（如某块区域被其他势力占领后，对应探索任务目标不再存在）

### 4.3 任务挂牌设定

玩家发布任务时需设定：

1. **赏金倍率**（见Section 5）
2. **任务专用装备**（可选，从仓库借出）
3. **报名截止时间**（可选；紧急任务可跳过等待期立即从当前在场冒险者中选人）

## 5. 赏金与报名系统

### 5.1 赏金倍率表

| 倍率 | 报名池规模 | 成功后忠诚度变化 | 玩家成本 | 适用场景 |
|------|----------|----------------|---------|---------|
| 0.5x | 极少（仅忠诚度≥60的冒险者） | +0 | 最低 | 资金极度紧张 |
| 0.75x | 较少 | +2 | 低 | 日常省钱任务 |
| 1.0x | 标准 | +5 | 标准 | 常规操作 |
| 1.25x | 较多，解锁更高等级候选 | +10 | 较高 | 重要任务 |
| 1.5x | 最多，吸引顶级冒险者 | +15 | 最高 | 高风险关键任务 |

### 5.2 冒险者AI报名决策逻辑

冒险者收到任务公告后，按以下规则决定是否报名：

```
1. 技术门槛：任务等级整数值 ≤ 自身等级整数值？
   → 否则拒绝（等级不够，不具备能力）
   → 注意：高等级冒险者可以接低等级任务，不做上限限制

2. 经济门槛：赏金倍率 ≥ 本人意愿阈值？
   → 否则拒绝
   · 意愿阈值由忠诚度决定（见下表）

3. 空闲检查：当前无其他任务在身？
   → 否则不可用

4. 通过以上全部检查 → 报名
```

**赏金意愿阈值（按忠诚度）**：

| 冒险者忠诚度 | 最低可接受赏金倍率 |
|------------|----------------|
| 80 ~ 100 | 0.5x（几乎无条件接） |
| 60 ~ 79 | 0.75x |
| 40 ~ 59 | 1.0x |
| 21 ~ 39 | 1.25x |
| ≤ 20（动摇） | 1.5x（极度挑剔） |

### 5.3 专属奖励系统

部分冒险者对特定任务类型有**专属奖励**加成，在派遣界面对玩家可见：

- 示例：某冒险者"讨伐专精"——讨伐任务成功后额外获得稀有材料
- 示例：某冒险者"遗迹探索者"——探索任务结束时额外触发一次寻宝
- 专属奖励触发后额外给予该冒险者 +5 忠诚度

专属奖励是玩家选人时的重要参考维度，形成"不一定选最强的，而是选最合适的"决策。

## 6. 任务执行

### 6.1 实时观战（主要模式）

- 派遣确认后，冒险者单位出现在游戏地图上，实时向目标移动
- 玩家可俯视观看全程，但**不能直接控制冒险者**
- 冒险者根据职业AI自主战斗、使用技能、处理遭遇
- 玩家唯一直接干预手段：提前召回（视为**主动撤退**，按轻度失败结算：冒险者无损失、装备返还、忠诚度 -10、任务奖励不发放）

### 6.2 事件选择卡（偶发）

任务执行中，部分关键节点弹出事件卡，玩家做选择：

示例事件：
- "队伍遭遇埋伏，是否消耗道具突围？" → 选项影响损失大小
- "发现神秘宝箱，是否冒险开启？" → 影响奖励或触发陷阱
- "冒险者受重伤，是否撤退？" → 主动撤退可保人，按**轻度失败**结算（同Section 6.1召回规则：冒险者无损失、装备返还、忠诚度-10、无奖励）

事件选择频率：每次任务 0~2 次，保持稀缺感。

## 7. 任务结算

### 7.1 成功结算

- 所有派遣冒险者获得任务经验（按贡献分配，高等级冒险者经验衰减）
- 忠诚度按赏金倍率规则上涨
- 借出装备**全额返还**
- 玩家获得任务奖励（资源/道具/情报/声望）
- 若触发专属奖励，额外发放

### 7.2 失败结算

| 失败类型 | 触发条件 | 冒险者 | 装备 | 忠诚度 |
|---------|---------|--------|------|--------|
| 轻度失败 | 主目标失败，全员撤退 | 无损失 | 全额返还 | -10 |
| 重度失败 | 有人员伤亡 | 概率永久失去部分成员 | 概率损毁 | -20 |
| 全灭 | 所有人阵亡 | 全部永久失去 | 全部损毁 | 剩余成员-20 |

**队伍平均等级计算**：将所有派遣冒险者的等级整数值求平均，四舍五入到最近整数，再映射回等级字母。例如 {B=5, D=3, C=4} → 平均4 → C级。

**失败概率表**（基于任务等级整数值 − 队伍平均等级整数值）：

| 等级差（任务 − 队伍） | 重度失败概率 | 全灭概率 |
|--------------------|------------|---------|
| ≤ 0（队伍等级 ≥ 任务） | 10% | 1% |
| +1 | 25% | 5% |
| +2 | 50% | 20% |
| ≥ +3 | 80% | 50% |

> 注：以上为基础概率，装备加成可降低（见8.2），事件选择结果可临时修改。

## 8. 任务专用装备

### 8.1 装备类型

| 类型 | 获取方式 | 任务后归属 | 失败后 |
|------|---------|-----------|--------|
| 借出装备 | 玩家从仓库选取 | 成功后返还玩家 | 轻度失败返还，重度/全灭概率损毁 |
| 任务消耗品 | 为任务单独购买 | 消耗不返还 | 无论成败消耗 |

### 8.2 装备对战斗的影响

装备通过**装备等级差**修正失败概率基础值：

| 装备平均等级 vs 任务等级 | 失败概率修正 |
|----------------------|-----------|
| 装备等级 ≥ 任务等级+1 | 重度/全灭概率各 −10% |
| 装备等级 = 任务等级 | 无修正（±0%） |
| 装备等级 = 任务等级−1 | 重度/全灭概率各 +5% |
| 装备等级 ≤ 任务等级−2 | 重度/全灭概率各 +15% |

> 装备修正与等级差修正叠加计算，概率下限为0%，上限为95%。
> 装备平均等级 = 所有借出装备的等级整数值均值，映射规则同冒险者等级。

## 9. 数值框架（初稿）

### 9.1 任务基础赏金（参考值）

| 任务等级 | 基础赏金 |
|---------|---------|
| F | 50 金币 |
| E | 150 金币 |
| D | 400 金币 |
| C | 1000 金币 |
| B | 2500 金币 |
| A | 6000 金币 |
| S | 15000 金币 |

### 9.2 经验需求（升级所需任务经验）

| 当前等级 | 升级所需经验 |
|---------|------------|
| F→E | 300 |
| E→D | 800 |
| D→C | 2000 |
| C→B | 5000 |
| B→A | 12000 |
| A→S | 不可升（S级仅随机触发） |

### 9.3 任务经验奖励（按等级差）

| 任务等级整数值 − 冒险者等级整数值 | 经验倍率 | 说明 |
|------------------------------|---------|------|
| 0（等级相符） | × 1.0 | 常规 |
| −1（低一级） | × 0.5 | 低效 |
| −2（低两级） | × 0.25 | 极低效 |
| −3 或以下 | × 0.1 | 几乎无收益 |

> **注**：根据Section 5.2的报名规则，冒险者不可接等级高于自身的任务（任务等级整数值 > 自身等级整数值的情况不会发生）。因此正差值行（+1, +2）不存在于正常流程中。若未来引入特殊机制（如组队中低等级冒险者跟随高等级队友参与超级任务），届时补充对应倍率。

## 10. 与其他系统的整合接口

| 系统 | 交互方式 |
|------|---------|
| 领地建筑系统 | 公会建筑等级决定可容纳冒险者上限 |
| 资源经济系统 | 赏金从玩家金库扣除，任务奖励进入金库 |
| 地图系统 | 任务执行在真实地图上发生，冒险者单位可见 |
| 声望系统 | 任务成功率和赏金慷慨度影响公会声望，声望影响招募质量 |
