利用 Python 和 OpenCV 实现“去光照（De-lighting）”的核心思路是：通过高度图重建地形的几何表面，模拟出与之匹配的光影，然后从原图中“除掉”这些光影。

以下是实现这一方案的完整步骤和代码逻辑。

3. Python 代码实现
import cv2
import numpy as np

def extract_albedo(image_path, heightmap_path, light_azimuth=45, light_elevation=45):
    # 1. 加载图像并归一化为浮点数 [0, 1]
    img = cv2.imread(image_path).astype(np.float32) / 255.0
    height = cv2.imread(heightmap_path, cv2.IMREAD_GRAYSCALE).astype(np.float32) / 255.0

    # 2. 计算高度图的梯度 (Sobel 算子)
    # ksize 越大，平滑度越高；scale 代表地形的陡峭程度系数
    scale = 10.0 
    dx = cv2.Sobel(height, cv2.CV_32F, 1, 0, ksize=3) * scale
    dy = cv2.Sobel(height, cv2.CV_32F, 0, 1, ksize=3) * scale
    dz = np.ones_like(dx)

    # 3. 归一化得到法线向量 N
    norm = np.sqrt(dx**2 + dy**2 + dz**2)
    nx, ny, nz = dx/norm, dy/norm, dz/norm

    # 4. 计算光源向量 L (从方位角和高度角转换)
    # azimuth: 0(北), 90(东)... elevation: 90(头顶), 0(地平线)
    az = np.radians(light_azimuth)
    el = np.radians(light_elevation)
    lx = np.cos(el) * np.sin(az)
    ly = np.cos(el) * np.cos(az)
    lz = np.sin(el)
    
    # 5. 计算模拟光照 Shading = N · L
    # 使用 clip 保证最小亮度，避免除以 0，同时模拟环境光(Ambient)
    ambient = 0.2
    shading = nx*lx + ny*ly + nz*lz
    shading = np.clip(shading, ambient, 1.0)

    # 6. 反向计算 Albedo = Original / Shading
    # 对 BGR 三个通道分别除以光照强度
    albedo = np.zeros_like(img)
    for i in range(3):
        albedo[:,:,i] = img[:,:,i] / shading

    # 7. 结果后期处理
    # 稍微提高对比度和亮度补偿，并防止溢出
    albedo = np.clip(albedo * 0.8, 0, 1) 
    
    return (albedo * 255).astype(np.uint8), (shading * 255).astype(np.uint8)

# 使用示例
albedo_res, shading_res = extract_albedo("terrain_orig.jpg", "heightmap.png")
cv2.imwrite("terrain_albedo.png", albedo_res)
cv2.imwrite("simulated_shading.png", shading_res)
4. 关键参数调优建议
scale (地形强度):
如果你生成的高度图非常平坦，增加 scale（比如设为 20）。
如果去光照后边缘有奇怪的黑边，减小 scale。
light_azimuth (光源方位角) 与 light_elevation (高度角):
这是最难对齐的部分。你需要反复测试，直到 shading_res（模拟光影图）里的山峰亮部和阴影位置与原图完全吻合。
技巧： 观察原图中的单棵树或独立小山的阴影指向。
ambient (环境光):
这个值决定了“最黑的阴影”有多黑。通常设在 0.2 - 0.3 之间。如果设得太低，除法运算会使阴影处产生巨大的噪点。
5. 这个方案的局限性
投射阴影 (Cast Shadows):
上述数学模型只能解决“背光面”变暗的问题（Shading），无法解决“一座高山把影子遮在另一座山上”的问题（Cast Shadows）。处理投射阴影需要更复杂的 Ray Marching（光线步进） 算法。
颜色溢出:
如果原图的阴影处已经是纯黑（像素值 0），那么数学上是无法还原其纹理的。
总结
这套 Python 方案配合 Depth-Anything-V2 生成的高度图，可以帮你洗掉原图中 70%-80% 的光影。得到的 albedo_res 将会是非常干净、平淡的贴图，非常适合再交给 OpenCV 进行纹理分类或在游戏引擎中使用。
