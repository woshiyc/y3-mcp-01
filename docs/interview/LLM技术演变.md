# 近 2 年 LLM 技术演进时间线（2024.01-2026.05）

> 涵盖主流落地技术、架构优化、推理范式、稀疏方案，同时标注**已淘汰 / 边缘化技术**，按时间阶段划分，适合查阅、复盘与技术梳理

## 一、整体说明

1. 时间范围：2024 年 1 月 — 2026 年 5 月
2. 分类维度：**当前主流技术**、**已淘汰 / 边缘化技术**
3. 覆盖方向：注意力机制、位置编码、模型架构、推理范式、训练优化、KV 缓存、稀疏结构、微调 / 强化学习、多模态 / Agent 等

---

## 二、2024 上半年（2024.01 - 2024.06）

### 核心方向

长上下文扩容、推理显存 / 速度优化、基础组件标准化、CoT 提示工程普及

### 一）主流在用技术

1. **GQA 分组查询注意力**
   
   - 作用：Q 多头、K/V 少量头，大幅降低 KV Cache 显存占用，推理提速 30%~50%
   - 现状：全行业标配，逐步替代原始 MHA

2. **RoPE 旋转位置编码**
   
   - 作用：支持长文本外推，位置与语义解耦，适配 KV Cache
   - 现状：全面成为主流位置编码方案

3. **滑动窗口注意力**
   
   - 作用：限制注意力计算范围，复杂度降至 O (n)，支撑 100K + 上下文
   - 现状：中长文本模型通用方案

4. **RMSNorm + SwiGLU**
   
   - 作用：RMSNorm 简化归一化、训练更稳定；SwiGLU 替代传统激活函数，表达能力更强
   - 现状：新模型基础组件标配

5. **KV Cache（前缀复用 + 量化优化）**
   
   - 作用：缓存历史 Token 的 K/V，仅计算新 Token 的 Q，推理核心加速方案；搭配 4bit/8bit 量化进一步降显存
   - 现状：推理必备，无替代方案

6. **CoT 思维链（提示工程阶段）**
   
   - 作用：通过 Prompt 引导模型分步推导，提升数学、逻辑、推理能力
   - 现状：推理能力基础方案，后续向模型内化演进

### 二）已淘汰 / 边缘化技术

1. 绝对位置编码（正弦编码、可学习位置编码）：被 RoPE 全面取代
2. 原始 MHA 多头注意力：显存开销过高，被 GQA 替代
3. Post-Norm 后置归一化：Pre-Norm 训练稳定性更优，成为主流
4. ReLU、传统 GELU 激活函数：被 SwiGLU 等 GLU 变体淘汰

## 三、2024 下半年（2024.07 - 2024.12）

### 核心方向

MoE 混合专家规模化、内生推理范式诞生、高阶稀疏注意力、FP8 精度普及、中间训练流程成熟

### 一）主流在用技术

1. **MoE 混合专家架构**
   
   - 作用：FFN 拆分为多组专家，单 Token 仅激活少量专家，实现**大总参数、低激活算力**，模型能力大幅跃升
   - 代表：Mixtral、DeepSeek-V2/V3
   - 现状：旗舰大模型主流架构，小模型仍以 Dense 密集架构为主

2. **慢思考推理范式 + RLVR 强化学习验证推理**
   
   - 起源：OpenAI o1 推理时延长思考链；RLVR 用奖励函数优化推理链路与答案正确性
   - 变化：CoT 从「Prompt 技巧」转变为模型内生能力
   - 现状：高端推理模型核心方案

3. **MLA 多级注意力（高阶稀疏注意力）**
   
   - 作用：分层动态注意力，复杂度 O (nlogn)，支撑百万级超长上下文
   - 现状：旗舰长文本模型采用，滑动窗口仍保留在常规长文本场景

4. **Mid-Training 中间训练**
   
   - 作用：预训练后、SFT 前，使用高质量长文本 / 推理数据继续训练，低成本提升模型上限
   - 现状：模型训练标准流程

5. **FP8 混合精度**
   
   - 作用：训练 / 推理显存减半、速度提升，精度损失可控，适配超大 MoE 模型
   - 现状：千亿级模型标配

### 二）已淘汰 / 边缘化技术

1. 早期稀疏注意力（Longformer、Reformer）：效率低于滑动窗口、MLA，彻底边缘化
2. 纯 SFT 有监督微调：缺乏推理优化，逐步被「SFT+RL」组合替代
3. 传统纯 LoRA 微调：千亿大模型场景转向全参数微调 / 专家微调，LoRA 仅保留轻量场景

## 四、2025 全年（2025.01 - 2025.12）

### 核心方向

强化推理能力、MoE 精细化优化、推理蒸馏、多任务混合训练、Agent 工具链成熟

### 一）主流在用技术

1. **RLVR + GRPO 分组强化学习**
   
   - 作用：无需依赖大量 SFT 数据，仅通过强化学习就让模型习得强推理；奖励兼顾答案与推理链路
   - 代表：DeepSeek-R1、GPT-o3 系列
   - 现状：推理模型核心训练方案

2. **精细化 MoE（专家分工优化）**
   
   - 升级：专家按领域分工（数学、代码、常识等），路由算法优化、负载均衡提升
   - 现状：开源 / 闭源旗舰 MoE 模型通用优化方向

3. **推理蒸馏**
   
   - 作用：将大模型的长思考链、推理能力蒸馏到中小模型，低成本提升小模型推理水平
   - 现状：轻量化推理模型必备方案

4. **MTP 多任务并行训练**
   
   - 作用：预训练、中间训练、SFT、RL 多任务混合训练，模型能力更均衡、收敛更快
   - 现状：新模型训练主流范式

5. **一体化 Agent 工具链**
   
   - 能力：模型自主规划、函数调用、检索、代码执行、结果迭代验证
   - 现状：商用模型标配，对话模型向执行型 Agent 演进

### 二）已淘汰 / 边缘化技术

1. 纯 Prompt 式 CoT：模型内生 RL 推理效果、稳定性远优于手工 Prompt CoT
2. 浅层简易 MoE（如 8x7B）：能力不足，被超大规模精细化 MoE 替代
3. 独立外挂多模态模块：统一原生多模态架构成为主流，分离式模块淘汰

## 五、2026 年初至今（2026.01 - 2026.05）

### 核心方向

推理时扩展、KV Cache 极致优化、动态稀疏架构、推理可解释与安全对齐

### 一）主流在用技术

1. **推理时扩展（Inference-Time Scaling）**
   
   - 作用：**不增加模型参数**，通过延长思考时长、多路径搜索、自我反思、多轮校验提升能力
   - 现状：当前核心技术方向，突破参数规模上限

2. **动态稀疏 + KV Cache 全链路优化**
   
   - 升级：动态选择注意力头 / 专家、KV 按需压缩、通用前缀离线缓存，进一步降低推理成本
   - 现状：高并发、超长文本场景刚需

3. **推理可解释 + 安全对齐（融入 RL 流程）**
   
   - 作用：推理链路可追溯、风险步骤自动拦截，对齐与推理训练一体化
   - 现状：企业级、合规类模型强制要求

### 二）已淘汰 / 边缘化技术

1. 简易调用式 Agent：无自主规划的基础工具调用被全链路规划型 Agent 替代
2. 大规模 LoRA 微调：仅用于个人 / 小场景微调，工业级大模型不再使用

## 六、技术路线迭代总汇总（横向对比）

表格

| 技术类别     | 旧方案（已淘汰）             | 主流当前方案                      |
| -------- | -------------------- | --------------------------- |
| 位置编码     | 绝对位置编码、ALiBi         | RoPE 旋转位置编码                 |
| 注意力机制    | 原始 MHA、Longformer 稀疏 | GQA + 滑动窗口 / MLA            |
| 激活 / 归一化 | ReLU、GELU、Post-Norm  | SwiGLU + RMSNorm + Pre-Norm |
| 模型架构     | 纯 Dense 密集模型（旗舰）     | MoE 混合专家（旗舰）                |
| 推理能力优化   | 手工 Prompt CoT、纯 SFT  | RLVR / GRPO 内生推理            |
| 推理加速     | 无缓存、简易量化             | KV Cache + 分页 / 动态压缩        |

---

## 七、演进核心脉络

1. **2024 上半年**：夯实底座 → 长上下文 + 推理提速，基础组件全面标准化
2. **2024 下半年**：架构升级 → MoE 规模化 + 推理范式革新，模型能力第一次大幅跃迁
3. **2025 全年**：能力内化 → 强化学习主导推理，蒸馏、Agent 落地，实用化成熟
4. **2026 至今**：效率深挖 → 不增参数、纯推理侧优化，极致降本 + 安全合规
