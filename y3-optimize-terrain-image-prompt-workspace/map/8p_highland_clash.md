# 地图：Highland Clash（高地争霸）
# 类型：8人RTS · 高低地攻防型
# 风格参考：魔兽争霸3多人竞技图 · 文明6战争地图
# 地图规模：代表约 320×320 格游戏区域（8人大图标准）

---

## 地图设计理念

高低地分层是核心——高地易守，低地资源丰富，形成魔兽争霸式的"打高地"攻防张力。
地形多变，有山脊、丘陵、峡谷交替出现，体现饥荒式的探索多样性。
整体开阔，适合大兵团作战，山脊与峡谷提供战术绕路空间。

## 优化后的正向提示词

这是一张类魔兽争霸3风格的8人RTS战略地图全览图，用于游戏编辑器图片转地形。地图为正方形，代表约320×320格的大型游戏区域，视角为从极高空完全垂直俯视全境，如同RTS游戏全图总览界面。画面内所有地形同时可见，没有任何局部特写，每处地形元素只占画面一小部分。地图内容填满整个画布，四边即地图边界，无倾斜、无透视、无留白、无边框。

地图由多层高度的地形构成，高低起伏，层次分明。低地走廊、丘陵草坡、高地台地、山峰棱线四层地形交替出现，形成复杂的立体战场。深水峡谷穿插其间作为天然屏障，浅水溪流提供局部通行通道。整体布局多变不规则，无明显轴对称，体现自然地形的随机感。

使用固定颜色语义表达地形，各区域颜色均匀纯粹：
- 深水峡谷（不可通行）：深海蓝，约 RGB(25,55,135)；宽阔色块，非细线
- 浅水溪流（可通行）：青蓝，约 RGB(70,165,205)
- 低地走廊（h=0）：浅草绿，约 RGB(130,185,95)
- 丘陵草坡（h=2）：橄榄绿，约 RGB(100,130,60)
- 高地台地（h=3）：深橄榄绿，约 RGB(75,105,40)
- 山峰棱线（h=4）：棕褐，约 RGB(130,90,55)

地形高度通过来自单一方向的柔和平行光表现明暗，高处明亮，低处和峡谷略暗，便于 DA3 深度估算。禁止多光源、电影感打光、戏剧性阴影。

整体风格：俯视奇幻战略地图，色块干净，地形层次丰富，适合 CV 聚类分割和 DA3 高度估算。

## 风险提醒

- 橄榄绿(100,130,60) vs 深橄榄绿(75,105,40) 色差约20，需验证 cluster_preview 是否分为两个聚类
- 棕褐山峰若面积过小会被 CV 过滤为噪点，建议总占比不低于7%
- 深水峡谷需完整连续，断开的峡谷会导致地形分割失效
