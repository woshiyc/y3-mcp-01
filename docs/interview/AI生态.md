# AI 工具与生态演进（2024.01–2026.05）

## 一、2024 上半年：工具爆炸 · 单点能力工业化（2024.01–2024.06）

### 1）生成类工具

- 图像：Midjourney V6、FLUX.1；质量达商业级
- 视频：Runway Gen-2、Pika Labs 1.0；4–8 秒短视频可用
- 语音/音乐：ElevenLabs、Suno AI；配音/播客/歌曲成本归零
  
  ### 2）办公生产力
- Microsoft 365 Copilot：Word/PPT/Excel 全链路 AI
- Notion AI、飞书妙计：会议纪要、知识库智能化
- 代码：GitHub Copilot X、Cursor；从补全到项目生成
  
  ### 3）RAG/企业知识库
- LangChain、LlamaIndex：私有数据接入
- Kimi（200万上下文）：长文档/论文分析
  
  ### 4）早期 Agent
- AutoGPT、BabyAGI：可上网调用工具，但易死循环
- GPTs：用户自定义小助手，C 端低门槛
  
  ### 已淘汰
- 无工具/无记忆的纯问答机器人
- 作坊式提示词工具

## 五、AI 工具生态 vs LLM 技术：影响对比

### LLM（大脑）

- 提升：推理、数学、逻辑、知识深度
- 影响：回答更准、更深、更少错
- 局限：不能直接操作世界、不能自动执行
  
  ### 工具+生态（手脚+系统）
- 提升：自动化、执行力、连接能力、场景覆盖
- 影响：工作重构、岗位替代、效率指数级增长
- 结论：**生态影响 > LLM 智商提升**
