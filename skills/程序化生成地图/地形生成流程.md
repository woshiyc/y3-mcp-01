完整生成流程
下面是一个比较实用的流程。

Step 1：生成宏观布局
确定地图主题：
    森林山谷
    湖泊平原
    火山裂谷
    山地村庄
    沼泽废墟
生成：

主山脉
低地区域
水源区域
危险区域
出生点
主要目标点
算法：

Voronoi
噪声
距离场
随机关键点
约束规则
Step 2：生成高度图
噪声基础高度
+ 山脉高度
+ 河谷下切
+ 湖泊低地
+ 火山锥
+ 平整建筑区域
算法：

fBm
Ridged Noise
Domain Warping
曲线山脉
高度平滑
坡度限制
Step 3：生成水域和岩浆
低洼区 → 水域
山地源头 → 河流
火山口 / 裂隙 → 岩浆
算法：

Flood Fill
Flow Accumulation
A*
Random Walk
Basin Detection
Step 4：生成生物群系
根据高度、湿度、温度、水距、岩浆距生成生物群系
算法：

温度湿度图
Voronoi 区域
Cellular Automata
Region Smoothing
Step 5：生成地面纹理
坡地 → 岩石
水边 → 泥地
高山 → 雪
森林 → 草地
火山 → 黑岩
道路 → 土路 / 石路
算法：

Rule-based Texture Assignment
Splat Map
Noise Blending
Distance Field
Step 6：生成道路
连接出生点、村庄、资源点、目标点
算法：

A*
Dijkstra
MST
Cost Map
Spline Smoothing
Step 7：生成建筑
选择平坦区域
靠近道路
远离岩浆和水域
形成聚落
算法：

Poisson Disk
Constraint Solving
Terrain Flattening
Collision Check
Step 8：生成植被、岩石、装饰物
根据生物群系、坡度、水距、道路距、建筑距摆放
算法：

Poisson Disk Sampling
Blue Noise
Density Map
Rule-based Placement
Spatial Hashing
Step 9：规则评分
自动计算：

连通性
坡度
可达性
建筑合法性
道路完整性
水域合理性
物体碰撞
危险区域距离
不合格直接淘汰。

Step 10：LLM / 视觉模型评分
输入：

俯视图
高度图
生物群系图
道路图
地图统计 JSON
输出：

审美分
风格分
问题列表
修改建议
Step 11：优化器调整参数
根据评分继续迭代：

如果太平 → 增加山地强度
如果太乱 → 增加平滑
如果水太碎 → 合并湖泊
如果道路不自然 → 提高坡度惩罚
如果森林太满 → 降低植被密度
如果缺少视觉焦点 → 增加地标
