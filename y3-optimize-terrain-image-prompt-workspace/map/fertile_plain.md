# 地图：The Fertile Plain（沃野）
# 风格参考：Majesty - 温带奇幻王国，开阔平原为主，双河流分割

---

## 地图描述

温带平原王国，以对称防御为核心。中央大面积草地是王国建造区，
东西各有一条深水河流构成天然屏障，北部有丘陵和混合森林过渡，
四角外圈有密林作为荒野危险区。整体平坦开阔，适合全方向探索与防御。

---

## 优化后的正向提示词

这是一张类Majesty奇幻策略游戏的完整地图全览图，用于游戏编辑器图片转地形，主题为温带奇幻王国沃野。地图为正方形，代表约128×128格的游戏区域，包含从首都到外圈荒野的全部游戏内容。画面视角相当于从极高空俯视整个王国全境，如同策略游戏全图总览界面——首都、河流、山脉、森林、外圈荒野全部同时可见，画面内没有任何局部特写，每一处地形元素都只占画面的一小部分。
地图内容必须填满整个画布，画面四边即地图四边界，不存在画外区域，无倾斜、无透视、无留白、无装饰边框。

使用固定颜色语义表达地形类型：
- 深水河流（不可通行）：深海蓝，约 RGB(25,55,135)
- 河岸/岸边：浅米黄，约 RGB(220,200,150)
- 草地平原（h=0）：浅草绿，约 RGB(130,185,95)
- 丘陵草坡（h=2）：橄榄绿，约 RGB(100,130,60)
- 密林区（h=2）：深橄榄绿，约 RGB(60,90,35)

地形高度通过自然光照明暗表现：丘陵和密林区自然明亮，平原居中，河谷和低洼略暗；使用来自统一方向的柔和平行光，使高处与低处有可见的明暗层次差异，便于深度估算模型（DA3）读取高度信息。禁止电影感打光、戏剧性强阴影、多光源。

整体风格为俯视温带奇幻策略地图，保留地形高低的自然光影感，适合计算机视觉进行水域识别、大陆分割和纹理分配，以及深度估算模型生成高度图。

## 风险提醒

- 丘陵橄榄绿 RGB(100,130,60) 与密林深橄榄绿 RGB(60,90,35) 色差需足够，否则被合并为同一大陆
- 平原浅草绿面积大，颜色若不均匀会产生大量碎片聚类，影响大陆分割精度
- 河流深蓝需完整贯穿地图，生成后验证河流是否断开
