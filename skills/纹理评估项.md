1.材质是否符合地形逻辑:
平缓区域：草地、泥土、沙地、雪地
陡峭区域：岩石、裸土
水边区域：湿泥、苔藓、卵石、芦苇
道路区域：压实泥土、碎石、车辙
建筑周围：踩踏痕迹、灰尘、泥地
山脚区域：碎石、坡积物
森林区域：落叶、腐殖土、苔藓
雪山区域：雪、冰、裸岩混合
2.地形材质是否支持区域辨识
1. 森林区、草原区、沼泽区、山地区、雪地区是否有明显地表差异？
2. 玩家只看地面颜色和材质，能否判断所在区域？
3. 不同区域的纹理是否过于相似？
4. 特殊区域是否有独特材质语言？
3.纹理是否服务玩法可读性
1. 主路是否容易识别？
2. 可战斗区域是否清晰？
3. 危险区域是否有视觉暗示？
4. 可采集资源附近是否有地表提示？
5. Boss 场地边界是否清楚？
6. 水深、沼泽、悬崖、不可通行区是否能被玩家看出来？
4.地形纹理与模型是否融合
纹理要和放置物自然融合。
关注：
1. 树根周围是否有泥土、落叶、苔藓？
2. 岩石底部是否有碎石、阴影、尘土？
3. 建筑地基是否和地面融合？
4. 道路是否连接建筑入口？
5. 怪物巢穴周围是否有污染、骨骸、粪便、刮痕等地表变化？
6. 农田、村庄、矿场是否改变了原始地表？
5.特殊区域纹理是否有叙事性
高级环境美术会通过地表纹理讲故事。
例如：
古战场：焦土、血迹、破旗、车辙、武器残片
废弃村庄：泥泞道路、杂草侵入、烧毁痕迹
龙巢：焦黑岩石、鳞片、骨骸、爪痕
亡灵墓地：灰土、枯草、墓碑碎片、阴冷色调
魔法污染区：发光裂纹、异常菌类、变色土壤
兽人营地：踩踏泥地、篝火灰烬、骨堆
最简单的纹理评估标准：它是否符合风格、比例正确、过渡自然、没有重复、符合地形逻辑、能区分区域、能融合模型、能服务玩法，并且性能可控。
可以把纹理评估放在这几个节点：
1. 地形初始生成后：检查坡度/高度/水边材质逻辑
2. 生态生成后：检查森林、草地、沼泽等区域纹理身份
3. 建筑生成后：检查道路、地基、踩踏痕迹和生活痕迹
4. 怪物/Boss 生成后：检查污染、破坏、危险区域纹理表现
5. 最终导出前：检查重复感、美观性、性能风险
