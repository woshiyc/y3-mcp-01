# 地形提示词优化输出

**原始描述：** 帮我优化一段地图生成提示词，用于图片转地形。我想要一张四人对战地图，中间有一座雪山，四角是玩家出生点，雪山周围有森林和两条河流，河上有桥。

---

## 优化后的正向提示词

一张用于游戏编辑器图片转地形的俯视正交地形规划图，主题为：四人对战雪山地图。地图内容必须填满整个画布，地图边界与图片边界严格对齐，无倾斜、无透视、无留白、无装饰边框。

地图布局：整体地图为四人对称对战结构。地图中央是一座高耸的雪山，雪山从外围向中心逐渐升高，形成清晰的高度层级。雪山顶部为灰白色或白色，中部为棕色山地，外围为灰棕色过渡区域。地图四角各有一处玩家出生点，以浅色平原区域标示，面积适中、对称分布。雪山周围包裹着两圈深绿色森林区域，森林以清晰的色块形式分布在山脚四周。地图中有两条河流，以青蓝色线状区域表示，从雪山外围向地图边缘延伸，连接四角出生点之间的区域；每条河流上有一座桥梁，以浅棕色或木色短线段表示，清晰跨越河道。

使用清晰、低噪声、机器可读的色块表达地形：深蓝色或青蓝色表示河流水域，浅黄色表示河流岸边，浅绿色表示平原和出生点区域，深绿色表示森林，橄榄绿或浅棕色表示低山丘陵过渡带，棕色和灰棕色表示中段山地，灰白色或白色表示雪山顶部。不同地貌区域边界清晰，颜色稳定，避免复杂纹理。

高度通过明确的离散高度色带表达：河流水域最低，岸边和平原较低，出生点区域处于低平位置，森林略高于平原，丘陵和低山逐渐升高，中央山地更高，雪山顶部最高。山脉区域从边缘到中心逐渐升高，形成容易识别的高度层级；河流保持低地特征，在地形中形成清晰的低洼通道。

道路、桥梁、森林、山脉等元素以简洁的区域或线条表达，不使用复杂图标。桥梁以简单短矩形色块跨越河流表示。整体风格为简洁战略地图、平面地形规划图、低纹理噪声、清晰区域分割，适合后续计算机视觉进行水域识别、大陆分割、纹理分配、高度推断和装饰物识别。

不要透视视角，不要斜视角，不要3D场景，不要电影感光照，不要强烈阴影，不要写实摄影，不要景深，不要云雾，不要复杂纹理，不要过度细节，不要随机噪点，不要模糊边界，不要文字，不要数字，不要地名标签，不要图例，不要罗盘，不要UI面板，不要水印，不要装饰边框，不要人物，不要怪物，不要车辆，不要大量小图标，不要复杂建筑插画，不要让森林由大量独立树冠组成，不要让山脉变成写实风景插画，不要让雪山呈现为照片级真实雪山，不要让河流变成细密流水纹理，不要让桥梁变成精细建筑结构图，不要出现多余水域以外的额外海洋或湖泊。

## 为什么更适合图片转地形

- 俯视正交视角消除了透视变形，保证图片坐标与地图网格坐标的1:1映射，避免因视角导致的地形还原错位。
- 明确的颜色语义（雪白=高山、深绿=森林、青蓝=水域、浅绿=平原）允许CV色彩聚类算法将像素直接映射到对应地形类型，无需歧义消解。
- 离散高度色带（平原→丘陵→山地→雪山顶）使高度推断模块可以按颜色层级直接还原地形高度，避免连续渐变带来的高度歧义。
- 禁用阴影、透视光照和复杂纹理，防止光影噪声干扰水陆分割和地貌分类。
- 桥梁以简单色块跨越河流而非精细插画，便于CV识别为可通行连接结构。
- 森林以清晰深绿色块表示而非大量小树图标，避免独立树冠图案干扰纹理分配和区域分割。
- 禁止文字、图例、罗盘、边框，消除非地形像素干扰整张图片的识别流程。
- 地图内容填满画布约束，确保图片边界与地形边界严格对齐，防止留白区域被错误识别为地形内容。

## 可选参数建议

- 画幅：1:1（四人对称地图推荐正方形画幅，保证四角出生点对称映射）
- 风格：flat terrain planning map / orthographic strategy map / game map blueprint
- 细节：中低（保留区域边界清晰度，避免引入复杂纹理噪声）
- 写实程度：低（确保色彩稳定，禁止写实光影）
- 随机性：中低（保证地图结构对称性和颜色语义稳定）
- Stable Diffusion 类：CFG 6~7，Steps 28~35，Sampler DPM++ 2M Karras，分辨率 1024×1024 或 2048×2048
- Midjourney 类：--style raw --ar 1:1 --stylize 30~60（压低风格化程度，保证地形色块清晰）

## 风险提醒

- 雪山顶部的灰白色与普通道路或亮色平原容易混淆，建议在图片生成后检查顶部颜色是否与平地区分清晰；如不清晰，可在提示词中强调"雪峰顶部纯白色，与周围棕色山地形成强对比"。
- 两条河流若生成位置不对称或宽度过细，可能导致水域识别遗漏；建议选取河流宽度明显（至少占地图宽度5%以上）的生成结果。
- 桥梁色块较小，CV识别时可能被忽略或与岸边混淆；建议在图片转地形阶段人工标注桥梁位置，或在提示词中补充"桥梁为浅棕色明显宽矩形，与蓝色水域形成强对比"。
- 四角出生点区域颜色若与平原过于相似，可能无法被识别为特殊功能点；建议在图片转地形后，手动在编辑器中标注出生点位置，而不依赖颜色识别。
- 部分文生图模型（如DALL·E）对俯视正交约束的遵从度有限，可能自动添加斜视角或3D感；如出现此情况，建议换用Stable Diffusion或Midjourney并加强负向提示词。
- 生成完毕后，交给 `y3-gen-terrain-from-image` 前，请确认图片满足：正交俯视、无文字、无图例、无罗盘、无装饰边框、水陆边界清晰、山地高度层级明显、地图内容填满画布、分辨率足够清晰。
